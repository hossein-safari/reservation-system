# گزارش بررسی نسخه پایه

تاریخ: ۲۰۲۶-۱۰-۲۴. این گزارش نتیجه اجرای محلی روی WSL Ubuntu 24.04 است؛ وضعیت هر اجرای CI را در تب Actions مخزن ببینید.

| بررسی | نتیجه |
| --- | --- |
| Ruff lint و format | موفق |
| mypy strict | موفق، ۲۴ فایل برنامه |
| pytest با SQLite | ۸ موفق، ۳ تست مخصوص PostgreSQL کنار گذاشته شد |
| pytest با PostgreSQL | ۱۱ موفق؛ رقابت رزرو، تأیید هم‌زمان پرداخت و constraint هم‌پوشانی نیز اجرا شدند |
| Alembic upgrade و check | موفق روی SQLite و PostgreSQL؛ تفاوت schema گزارش نشد |
| ESLint و Prettier | موفق |
| Vitest 5 | ۵ تست موفق پس از بازطراحی فرانت |
| TypeScript و Vite build | موفق |
| npm audit | در زمان بررسی صفر آسیب‌پذیری گزارش‌شده |
| Docker build و Compose | هر سه سرویس db/api/web سالم؛ api و web با کاربر غیر root |
| مرورگر Chrome واقعی | گردش مدیر تا مشتری، رزرو، پرداخت آزمایشی و نمایش تراکنش موفق |
| نمایش responsive | دسکتاپ ۱۴۴۰ پیکسل و موبایل ۳۹۰ پیکسل، بدون overflow افقی |
| نسخهٔ Docker در مرورگر | proxy API، CSP و فونت محلی موفق؛ بدون خطای console/JavaScript |

تست شکست درگاه تأیید می‌کند که رزرو pending باقی می‌ماند و تراکنش موفقی ثبت نمی‌شود. تست مالکیت دسترسی حساب دیگر به لغو/پرداخت را رد می‌کند. تست تکرار verify و رقابت چند درخواست فقط یک تراکنش می‌سازد.

تصویر [رابط نمونه](assets/overview.png) از دادهٔ آزمایشی و محیط جدا گرفته شده است. مرورگر به دیتابیس موقت SQLite متصل بود؛ تست هم‌زمانی به دیتابیس PostgreSQL موقت اختصاصی متصل شد. داده‌ها و حساب‌های آزمایشی به دیتابیس اصلی پروژه منتقل نشده‌اند.

آزمون بانک واقعی، بار عملیاتی و refund در این گزارش وجود ندارد؛ این قابلیت‌ها در محدوده نسخه پایه نیستند. محدودیت‌ها در [نیازمندی‌ها](requirements.md) و [امنیت](security.md) ثبت شده‌اند.

بازطراحی رابط با بررسی فرم مدیریت، گردش رزرو تا پرداخت، Escape در dialog و شش عرض از ۳۲۰ تا ۱۹۲۰ پیکسل تکمیل شد. قواعد و تصاویر جدید در [سیستم بصری](design-system.md) آمده‌اند.
