# سیستم بصری مینیمال قرار

رابط از یک هدر کوتاه، ناوبری متنی و فهرست یک‌ستونه تشکیل شده است. رنگ‌ها خنثی، فاصله‌ها منظم و خطوط جداکننده کم‌رنگ‌اند. عنوان‌ها و متن از یک خانوادهٔ فونت استفاده می‌کنند.

## پایه‌ها

| توکن | مقدار | کاربرد |
| --- | --- | --- |
| `--background` | `#faf9f6` | زمینهٔ اصلی |
| `--surface` | `#ffffff` | سطح ورودی و دکمه |
| `--ink` | `#2c302d` | متن و دکمهٔ اصلی |
| `--ink-soft` | `#6b716b` | توضیحات |
| `--rule` | `#e3e4de` | خطوط جداکننده |
| `--radius` | `4px` | دکمه، ورودی و پیام |
| `--radius-dialog` | `6px` | پنجرهٔ ورود و پرداخت |

فونت Vazirmatn با وزن‌های ۴۰۰، ۵۰۰ و ۶۰۰ به‌صورت محلی بارگذاری می‌شود. مجوز آن در `frontend/public/licenses/` است. عرض محتوای دسکتاپ حداکثر ۱۰۸۰ پیکسل و عنوان صفحه ۲۵ پیکسل است.

## ساختار CSS

ورودی `frontend/src/styles.css` ترتیب لایه‌ها را مشخص می‌کند:

1. `tokens.css`: رنگ، فونت، فاصله و ردیوس.
2. `base.css`: پیش‌فرض عناصر، فوکوس و کاهش حرکت.
3. `layout.css`: هدر، ناوبری، صفحه و پاورقی.
4. `booking.css`: ردیف سانس، رزرو، رسید و وضعیت خالی.
5. `controls.css`: دکمه، فرم، پیام و dialog.

قواعد جدید را در لایهٔ مربوط قرار دهید. رنگ و ردیوس را از توکن‌ها بخوانید و از افزایش specificity یا `!important` برای حل تداخل استفاده نکنید.

## رفتار

- سانس‌ها بر اساس روز تهران گروه‌بندی می‌شوند. ردیف‌ها فقط زمان، فضا، مدت، مبلغ و عمل رزرو دارند.
- در موبایل، ناوبری زیر هدر و فیلتر زیر عنوان قرار می‌گیرد. اطلاعات هر سانس در یک ردیف فشرده با دو سطر نمایش داده می‌شود.
- فرم مدیریت، ورود و پرداخت از همان کنترل‌ها و ردیوس استفاده می‌کنند.
- وضعیت‌ها هم متن دارند و هم رنگ. فوکوس صفحه‌کلید مشخص است و لینک عبور به محتوا وجود دارد.
- dialog بومی، فوکوس را نگه می‌دارد و با Escape بسته می‌شود؛ هنگام انجام عملیات بستن آن غیرفعال است.

## بررسی

پنج تست فرانت، ESLint، Prettier، TypeScript و build موفق بودند. گردش مدیر و مشتری تا رزرو، پرداخت و رسید در مرورگر واقعی بررسی شد. عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل بدون اسکرول افقی بررسی شدند.
